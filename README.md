# 🏰 Mapa Interativo e Calculadora de Viagem de Baróvia

Aplicação web interativa para cálculo de rotas, tempo de viagem, ciclo dia/noite e clima em **A Maldição de Strahd (Curse of Strahd - D&D 5e)**.

## 🚀 Como Hospedar no Streamlit Community Cloud (Gratuito)

1. **Crie uma conta no GitHub** (se ainda não possuir) em [github.com](https://github.com).
2. **Crie um novo Repositório**:
   - Nomeie o repositório como `barovia-mapa-streamlit`.
   - Marque como **Public** (Público).
3. **Faça o Upload dos Arquivos**:
   - `app.py`
   - `requirements.txt`
   - `mapa_de_barovia.png` (a imagem do seu mapa de Baróvia)
4. **Implante no Streamlit**:
   - Acesse [share.streamlit.io](https://share.streamlit.io) e faça login com sua conta do GitHub.
   - Clique em **"New app"**.
   - Selecione o repositório `barovia-mapa-streamlit`, a branch `main` e o arquivo principal `app.py`.
   - Clique em **"Deploy!"**.

Sua aplicação estará no ar em um link público como `https://barovia-mapa-streamlit.streamlit.app`!
